competing page states it flatly. DOBI says carriers "may not be able to
limit the benefit as described" because federal parity preempts it for
group plans. The section explains which of three buckets a reader is in,
because that is the actual answer.

**A quoted state credential rule mentions technician certification.**
The house rule is Behavior Technician in our own voice. The state plan's
own wording is reproduced where it IS the coverage rule, and the
certification is named descriptively rather than by acronym, so the gate
that bans the acronym still passes.

**The `author` reference is left null.** All 349 existing posts point at
a BCBA record. The standing rule is not to attribute blog posts to named
BCBAs, so this one does not. If the template renders an empty byline,
that is the thing to check before publishing.
