# FAQ schema + OG images + navy padding (2026-08-09)

Per "implement both" (FAQ schema and OG images) plus "decrease the blue
padding on state pages slightly". All staged and verified on the staging
subdomain; rides to production on the next production publish.

- FAQPage JSON-LD generated by tools/tier1/gen-faq-schema.py from each
  page's real mm-faq accordion in the part2 embeds (gates: >=3 pairs,
  non-empty answers, no RBT token; copy verbatim, tags stripped). Stored
  merged with the untouched Service object as {"@context", "@graph":
  [Service, FAQPage]} - the schema endpoint rejects top-level arrays.
  All 12 pages verified rendering both types, 6 questions each.
- OG images: 1200x630 JPEG center-crops of the hero photos, 11 assets,
  CDN bytes cmp-verified; the two transition-planning pages share the
  dishwasher crop. openGraph.imageUrl set on all 12 (API rejects
  imageAssetId null alongside imageUrl, so imageUrl-only was written).
- Navy hub padding: the mm-svc bottom clamp on the three hub pages went
  clamp(40px, 5vw, 64px) -> clamp(28px, 5vw, 36px) (the rule was clamp-
  based, not the flat 64px measured at desktop). Renders 36px at 1440w,
  verified on all three hubs.
- Sitemap: includeInSitemap flipped true on the 12 pages via the beta
  sitemap API; staging sitemap now lists 12/12 (607 URLs). The robots
  noindex meta is a SEPARATE, API-inaccessible Designer page setting:
  Pages panel -> gear -> SEO settings -> "Exclude this page from search
  engine indexing" -> off, per page, then publish. Still on as of this
  commit; the client is flipping it.
